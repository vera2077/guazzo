feat: Info panel — where the pointer is, what colour is under it, how big the selection is

The second of the missing panels. Photoshop's Info is a read-out: nothing here
changes the document, so it can follow the pointer without a debounce.

The panel is a dumb view (buildInfoPanel returns an update() closure that only
writes text). The shell samples the composited colour with the same sampleColor
the eyedropper uses — so the Info colour and the picked colour cannot disagree —
and updates Position on pointermove, Canvas and Selection from render(). The
sample helper reads the flat cache, not the document, so the panel does not add
to the coupling metric.

The smoke asserts the card, its four values, and that the Canvas row carries a
size; removing the render update leaves "—" there and fails the assertion, so it
cannot pass for a card that was built but never filled.
