# Guazzo 1.15.1

## What changed

**A second launch now says so.** Guazzo opens one window, which means one
WebView2 profile; starting a second copy used to fail inside WebView2 with
`0x800700AA — The requested resource is in use` and show that as a stack-trace
dialog, which reads like a crash. The process now holds a named mutex and a
second start shows *"Guazzo is already running — switch to the window that is
already open"*, with the Task Manager sentence for the case where a previous
session died without closing its window.

That is the whole change: no editor behaviour differs, and the 1.15.0 installer
and rendering fixes are unchanged.

## Verification

- `70 test files / 703 tests`; lint, pins and smoke green; deterministic build.
- Started twice in a row: the first window stays, the second shows the message
  and exits without touching the WebView2 profile.
- The installer was rebuilt from this commit and its install → launch →
  uninstall cycle re-run.

## Limits

- Unsigned, as before: SmartScreen will warn.
- The guard is per user session (`Local\`), so a second copy in another session
  is still possible; the WebView2 folder is per user, so that is the only case
  it cannot separate.
