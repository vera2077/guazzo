# Guazzo 1.2.0

Performance only. Nothing in the interface changes, no file format changes, and
project and PSD files round-trip exactly as they did in 1.1.1.

## What got faster

**Perspective Crop** no longer copies the quad's bounding box into a byte buffer
*and* a float buffer before sampling. It reads one strip of 64 destination rows
at a time, with the source window derived from that strip's four mapped corners.
Working set for a full-canvas quad on a 16384² document: **5.37 GB → 4.4 MB**.
A full-canvas quad on 8192² takes 13.4 s instead of a memory failure.

**Select and Mask output** builds the resulting layer mask through one 256² tile
scratch instead of a bounding-box-sized copy of the selection: at 16384²,
**268 MB → 64 KB** for a select-all. The six combinations of selection shape and
hidden/shown polarity hash identically before and after.

**Move** touches only the union of the layer's old and new content, instead of
clearing and rewriting the whole canvas on every pointermove. A 256 px layer on a
2048² canvas: **11.3 ms → 0.5 ms** per pointermove. A full-canvas layer: 33.3 ms
→ 21.9 ms.

## What did not change

The feature set is 1.1.1. Filters, adjustments, text, pen, selections, healing,
PSD import/export, project save/load, autosave and native dialogs are untouched.

## Verification

- `node scripts/ci.mjs`: 59 test files, **605 tests**, 85 static pins, the
  headless smoke, and a deterministic single-file build.
- The new Move window is compared against a deliberately naive full-canvas
  implementation for seven offsets, masked and unmasked; dropping the union or
  the stationary pass each fail that test.
- The perspective rewrite is A/B'd against the previous implementation on six
  quads (identity, trapezoid, rotated, off-canvas, edge, tall) with real pixel
  content including transparent holes and half-transparent bands: every output
  and every per-layer hash is identical.
- `app-single.html` is reproducible from the tag with a clean clone.

## Known limits (unchanged, documented)

- One selection undo entry snapshots the whole mask: 268 MB at 16384², so a
  full-canvas selection can evict older pixel history. The real fix is
  copy-on-write mask tiles.
- A full-canvas Move still rewrites the layer on every pointermove (95.5 ms at
  4096²).

## Installing

Unzip `Guazzo-v1.2.0.zip` anywhere and run `Guazzo.exe`. WebView2 is already on
Windows 10 and 11. The exe is **unsigned**, so Windows SmartScreen will say
"Unknown publisher" the first time; choose "More info" then "Run anyway" if you
trust where you got it. Verify the download with `SHA256SUMS.txt` (or
`Guazzo-v1.2.0.zip.sha256` for the archive).
