# Guazzo 1.18.8

Undo, crash recovery and layer geometry, corrected.

## Recovery no longer destroys sessions it never offered

The recovery bar can show one snapshot, but a crashed session can leave several
on disk (the live slot, the recovery slot, the parked one, the archive). Restore
and Discard deleted them **by name**, so restoring the snapshot you were shown
could delete a different session's only copy.

Both now compare bytes: a slot is removed only if it holds the very snapshot
you restored or discarded. A distinct session stays for the next launch, and a
duplicate of the offered snapshot is no longer labelled "an older autosave from
…" — that label made a second boot look like two sessions when it was one file
written twice.

## Add Layer Mask can be undone

With a selection active, Ctrl+Z after "Add Layer Mask" restored the mask's
pixels and polarity but left the mask attached — so the layer kept a mask the
document never had, the paint target stayed on it, and saving wrote it. The
entry now remembers whether the mask existed before and detaches it on undo,
re-attaches it on redo.

## Free Transform pivots on the pixels again

Move writes the union of where the content was and where it lands, and its undo
fills the vacated area with transparent tiles. Those tiles hold nothing but they
still count as allocated, and Free Transform uses the allocated bounds as its
pivot and centre — so after a move (or an undo) rotating or scaling orbited the
old footprint instead of the layer. Empty tiles are now released after a Move
and after an undo.

## Smaller corrections

- Undo and redo arm an autosave: a snapshot could otherwise still contain the
  edit you undid, and restoring it re-applied that edit.
- A fourth distinct crash session no longer overwrites the archive slot; the
  older archive is kept and the refusal is logged.
- The installer's GUI probes the path it validated, not the raw text from the
  folder box.
- `verify-asset` reports a malformed `installerInputs` instead of throwing a
  `TypeError` while building the error message.

## Verification

- `node scripts/ci.mjs` — 79 test files / 812 tests, 114 pins, smoke, and the
  deterministic single-file build.
- New tests: a zeroed tile is released and a painted one kept; the undo of a
  freshly added mask detaches it and redo re-attaches the same mask.
- `payload.bin` is still proved against the shipped Setup and
  `verify-asset` still requires the installer hash, the Setup entry and the
  payload's six files.
