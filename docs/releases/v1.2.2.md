# Guzzo 1.2.2

Two correctness fixes, a release pipeline that can now be caught lying, and the
accessibility work a review asked for.

## Fixed

- **A cropped hide-polarity mask no longer comes back revealed.** Perspective
  Crop copied every layer property except `maskHide` and then read the mask with
  the reveal default, so a layer whose mask hid almost everything returned almost
  fully visible. The crop now carries the polarity, uses it as its "untouched"
  value, and seeds a fresh destination tile as hidden.
- **A Move drag composites the rectangle it changed, once.** 1.2.0 scheduled a
  whole-document composite and then let the next frame recomposite it, because
  the partial path never marked the cache as composed. `applyLayerMove` now
  returns the rect it wrote and the drag composites the union of the old and new
  content.
- **Selecting a shape with a feathered prior mask no longer leaves part of the
  old mask visible**: `fillMaskFromSelection` tested `prior > 127`, so coverage
  of 1–127 outside the new selection stayed shown.

## Release integrity

- A signature must now name the publisher: staging requires
  `RELEASE_REQUIRE_SIGNER` (subject substring or thumbprint) and fails closed
  without it, so any valid certificate is not enough.
- `SHA256SUMS.txt` and `RELEASE.json` hashed different copies. One map feeds
  both, the checksum list covers `RELEASE.json`, and the release swap keeps a
  backup instead of deleting the previous folder first.
- `package.mjs` re-derives every hash from the bytes it is about to zip, and
  `scripts/verify-asset.mjs` checks the exact zip the workflow publishes.
- The release workflow published `app/release/…` (the repository root is
  `app/`), interpolated `github.ref_name` into PowerShell, and used mutable
  action tags. It now names the staged folder, reads the ref from the
  environment, verifies the bytes it uploads, and pins every action to a
  commit; a static pin fails the gate if any of that regresses.

## Accessibility

- The canvas focus ring was `1px dashed` in a colour measuring 1.98:1, i.e.
  below the 3:1 floor for focus indicators; it is now 2 px solid accent
  (5.03:1).
- Three layer colour tags measured 3.65–3.94:1 against the panel as text; they
  are lighter now.
- Status-bar refusals carry `role="status"` and `aria-live="polite"`.
- The command palette registers in the dialog stack, so one Escape no longer
  closes both it and the dialog underneath.
- The layer button row wraps instead of squeezing eleven 28 px buttons toward
  each other.

## Gate quality

- The minimum test-file count tracked a 47-file tree (59 now, 613 tests).
- Stage 5 called `check()` optionally, so renaming that export printed green
  having verified nothing.
- The CSP pin accepted any policy, including `default-src *`; it now checks the
  directives the app relies on. The capability pin is parsed instead of grepped.
- The one wall-clock assertion in the suite now counts `composite()` calls.

## Known limitations

- The executable is **unsigned**, so Windows shows "Unknown publisher" on first
  run. Code signing is a paid, hardware-bound process (see `docs/SIGNING.md`);
  the pipeline is ready for a certificate but none is configured.
- There is no installer and no auto-updater: download the zip, extract, run
  `Guazzo-v1.2.2.exe`. `WebView2Loader.dll` must sit beside it.
- 16-bit-per-channel PSDs import as 8-bit, clipping values above 255, and the
  import report says so. CMYK and Lab are not supported.
- Two 16k limits are documented in `docs/PERFORMANCE.md`: a full-canvas
  selection's undo entry snapshots the whole mask, and a Move drag rewrites the
  whole layer per pointermove.

## Verify

`sha256sum -c SHA256SUMS.txt` inside the extracted zip. The archive's
`RELEASE.json` names the commit, the build inputs and the artifact hash; a
`v1.2.2` clone rebuilds `app-single.html` byte-identically.
