# Guazzo 1.18.10

Undo, recovery, release integrity and code-scanning fixes. This is the first
release whose installer payload is attested to the commit it ships from.

## Moving and transforming masks

- A mask-only Move (a layer with pixels but no raster content) now records an
  undo step. Previously the history entry was gated on the pixel snapshot, so
  moving a mask could not be undone.
- Free Transform and Move release fully empty mask tiles, so masks no longer
  accumulate swept tiles toward the project's tile cap. Released tiles of a
  hide mask are now read back with that mask's neutral, which keeps hidden
  bands hidden across consecutive transforms.
- Undo/redo of a transform restores mask tiles with the mask's polarity
  neutral instead of zero, so a released tile cannot come back as a revealed
  ghost.

## Recovery

- “Restore <date> instead” now keeps the bar open and names documents that
  failed to rebuild, drops the untouched boot tab, and retires the earlier
  snapshot after the restored tabs are written — but only for a complete
  restore. A partial one keeps its only copy on disk.
- The earlier-snapshot button includes the time, so two snapshots from the
  same day are distinguishable.
- A settled recovery bar lets Tab leave it: the bar no longer swallows the key
  before deciding there is no answer left to cycle to.

## Release integrity

- Staging refuses a dirty tree when an untracked file is a build input, and
  parses Git's NUL-separated status so unusual filenames cannot hide one. The
  gitignored shipped page is rebound to a fresh deterministic build before
  staging.
- The GitHub release workflow is now an honest gate, not an unreachable
  rebuild-and-publish path: CI cannot reproduce the maintainer's exe, so
  releases are cut locally from the committed payload.
- The local release binds `installer/assets/payload.bin` to the tagged commit.

## Code scanning

- The cargo mirror validates request paths against a two-origin HTTPS
  allowlist before fetching, uses content-hashed cache names, and returns a
  fixed plain-text 502 instead of reflecting exception text.

## Verification

- `node scripts/ci.mjs` — 80 test files / 822 tests, pins, smoke, and the
  deterministic single-file build.
- `verify-asset.mjs` checks the zip, Setup and payload against `RELEASE.json`
  and the committed `installer/assets/payload.bin`.
