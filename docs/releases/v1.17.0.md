# Guazzo 1.17.0 — Brush Settings

A brush panel, not a brush redesign: the size, hardness, opacity and flow
sliders stay on the options bar, and the dynamics that decide what an individual
dab looks like move into one dialog with a preview.

## What is new

**Brush Settings** (the button next to Pressure) opens an index of thirteen
sections. The ones that change the stamp:

- **Brush Tip Shape** — size, angle, roundness and spacing. Spacing is a
  percentage of the tip radius; the default is 25 %, which is exactly the old
  fixed value, so an untouched brush paints as before.
- **Shape Dynamics** — size, angle and roundness jitter, with a minimum
  diameter so a thin stroke does not disappear, and a Control that can follow
  pen pressure or tilt.
- **Scattering** — spread, Count and Count Jitter, with Both Axes.
- **Texture** — fine, coarse or chalk grain, scale, depth and Invert. The grain
  is deterministic, so a stroke can be replayed and the preview matches it.
- **Color Dynamics** — hue, saturation and brightness jitter, plus a foreground/
  background mix and Purity.
- **Transfer** — opacity and flow jitter.
- **Noise** and **Wet Edges** — per-dab grain and darker rims.
- **Smoothing** — the same pulled-string smoothing the bar exposes; the two
  now read one number instead of two.

Two sections are preferences rather than new rendering paths, and the panel says
so in place: **Build-up** (Guazzo's dabs already accumulate within a stroke) and
**Protect Texture** (there is one texture per brush, so nothing to protect it
from). Their numbers are remembered either way.

The preview draws a 90-position stroke through the same `dabVariation` the
brush calls, so it cannot show a stroke the canvas would not paint.

The recipe is stored under `guazzo.brush.v1` and survives a restart.

## What could hurt you

- **Still one stroke, one undo step.** Dynamics change the dabs, not the
  history model.
- **Dynamics apply to the brush and eraser only.** A heal, clone or dodge stamp
  stays one dab per position: jitter on a repair stamp makes the repair
  impossible to reason about.
- **Count is capped at 20 per position.** At 20 with full scatter a fast stroke
  stamps a lot of dabs; the cap is there so a stray setting cannot freeze the
  brush.
- **Scatter amplitude is in tip radii, not document pixels.** Scattering at
  100 % moves a dab one tip-width, so the same setting looks wilder with a
  large brush — that is the intended reading.

## Verification

- Engine tests: 9 new in `src/engine/tests/brushsettings.test.ts` — clamps,
  Count, Both Axes, the minimum-diameter floor, pressure control, seeded replay,
  grain determinism and Invert, colour-channel range.
- Smoke: the panel is opened from the options bar, all thirteen sections are
  found, selecting a section changes the page, a toggle is switched on, OK
  persists it, and reopening shows the saved state.
- Both were mutation-probed: removing the save call fails `OK must persist Shape
  Dynamics as switched on`; forcing Count to 1 fails `scatter: Count 3 stamps
  three dabs from one cursor position`.
- Full gate: 72 test files, 735 tests, pins, smoke and the deterministic
  single-file build.
