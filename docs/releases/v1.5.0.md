# Guazzo 1.5.0

Gradient Map is a live adjustment, and it survives Photoshop.

## What changed

- **Gradient Map is a real adjustment layer kind.** Shadows, an optional
  midtone and highlights map luminance through a colour ramp — live, masked and
  blendable like every other adjustment, not a destructive command that bakes
  into pixels.
- **It has settings you can reopen.** "Adjustment Settings…" reopens the map
  with the colours you chose; the midtone swatch only appears when the midtone
  is on, so the two visible wells are exactly the two stored stops.
- **It round-trips through PSD.** Export writes a solid gradient-map record with
  its colour stops; import reads Photoshop's stops back into the recipe instead
  of admitting a loss. A noise gradient is still admitted honestly — it has no
  stop list to carry — and a map with fewer than two readable stops falls back
  to the documented whole-document composite rather than writing a record that
  would open as an identity ramp.
- **The layer compiles to a lookup table.** One 256-entry table indexed by
  luminance, so a full-canvas map costs a lookup per pixel rather than
  interpolating between stops; the destructive and live paths agree within one
  rounding level, which a test pins.

## Verified

- `61 test files / 644 tests` green, 85 pins, smoke, deterministic artifact.
- Engine: the live layer matches the destructive Gradient Map within one level
  on every byte, endpoints are the stop colours (not greys), held ends hold.
- PSD: the record is sorted and carries `location`/`midpoint`; `ag.writePsd` →
  `readPsd` → import returns the same two stops with no `adjustment` admission.
- Project: the stops survive save/load and the composite is byte-identical.
- Smoke drives the dialog: pick colours, save, reopen, edit the shadow stop, and
  the saved project shows the edited colour. Mutation probe (shadow stop forced
  to black) fails the assertion that the saved stop is the colour the user picked.

## Limitations

Unsigned executable (SmartScreen will warn), no installer, no auto-updater.
Noise gradients are imported as their colour ramp with an admission; selective
colour, colour lookup and channel mixer are still not live kinds.
