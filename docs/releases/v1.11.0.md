## Guazzo 1.11.0

Drop a picture where you want it.

- **On the canvas** — the image becomes a new layer in the document you already
  have open: scaled down to fit if it is larger than the canvas (never upscaled),
  centred, and named after the file. One undo removes it.
- **On the tab bar** — the same image opens as its own project, leaving the
  current document untouched.
- Anything that is not an image (a project file, a PSD, a flat file) still opens
  by path wherever you drop it.

Before this, every dropped file went to "open", so a photo dropped on a canvas
silently replaced the project you were working on.

### Verification

- 66 test files / 682 tests, gate green, pins and deterministic build included.
- `placeRect` is unit-tested for the four cases that matter: smaller than the
  canvas (centred, full size), larger (both axes scaled), exact fit, and a
  degenerate 0×0 image (clamped to one pixel rather than producing an empty layer).
- The routing is smoke-tested in both directions and mutation-probed: forcing all
  files back through "open" turns the canvas assertion red (and leaves 1 tab
  instead of 4, which is the bug this replaces); forcing a tab-bar drop to place
  instead of open turns the tab assertion red.
- Harness fixes found by this feature: the smoke `document` had no `console`, its
  `closest()` ignored `#id` selectors, its elements had no `.id`, and layer rows
  are counted through the panel body rather than the panel element.

### Limits

- Only raster images can be placed: PNG, JPEG, WebP, GIF, BMP, TIFF. PSD, SVG and
  PDF still open as documents; a placed image is a normal pixel layer, not a smart
  object, so re-scaling it later resamples.
- The drop target is decided by where the pointer is: canvas or tab bar. Dropping
  on the layers panel behaves like dropping on the tab bar (it opens).
