# Guazzo 1.2.4

Fill layers can be created at all, and they can hold a gradient.

## New

- **Layer ▸ New Fill Layer…** — a fill layer existed in the model and the PSD
  importer could build one, but no surface in the app could make one. The dialog
  offers a solid colour, a **linear** gradient, or a **radial** gradient, with
  two colour stops and an angle for the linear case.
- **Gradients stay live.** A gradient fill is evaluated per document pixel at
  composite time, so it survives a canvas resize and can be re-edited, the way a
  fill layer should. Persisted as `fillGradient` in `.guazzo.json`.
- **PSD export is honest about it.** A PSD solid-colour record has one flat
  colour, so a gradient fill takes the existing single-composite fallback: the
  exported picture keeps the gradient, and the export says why the tree was
  flattened instead of silently freezing one stop.

## UI follow-ups from the review

- A long crop now shows a busy state before it starts: the warp runs after a
  paint, so a 13-second 8192² perspective crop no longer looks like a frozen app.
- The menu bar exposes `role="menubar"` / `menuitem` with `aria-expanded`, and
  Left/Right walk the top-level menus.
- Selecting a layer with the arrow keys scrolls it into view; the tree keeps its
  roving tabindex.
- The command palette's own smoke check asserted a render artefact rather than
  the action (four `New …` rows had made the layer count move by three without a
  row running). It now asserts the history entry the action pushes.

## Documentation

- `README.md` reduced from 292 to 169 lines; the module map moved to
  `docs/ARCHITECTURE.md` with the layering rules and a description of the gate.
- Changelog refreshed through 1.2.4.

## Verified like the rest

- `node scripts/ci.mjs` — 60 test files / 626 tests, 85 pins, UI smoke,
  deterministic single-file build.
- Eight new gradient tests (endpoints, radial symmetry, channel clamping,
  unsorted/missing stops, document-space scaling) plus a compositor test and an
  io round trip; the compositor test was mutation-probed by dropping the gradient
  branch, which fails it.
- Published artifact reproduces byte-for-byte from a clean clone at the tag.

## Known limitations

- The build is **unsigned** (no certificate), so Windows shows "Unknown
  publisher" and SmartScreen may warn on first run.
- Portable zip only: no installer, no updater. Update by replacing the folder.
- PSD round-trip limits are documented in `docs/COMPAT.md`.
