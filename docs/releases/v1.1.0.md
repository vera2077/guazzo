# Guazzo 1.1.0

1.1.0 is 1.0.0 with the licence settled and the repository made honest. The
editor itself is unchanged — same engine, same gate, same tests (59 files, 598
tests).

## The source is now Apache-2.0

1.0.0 shipped a proprietary EULA. 1.1.0 ships the Apache License 2.0, verbatim
and unmodified apart from the appendix line that names the copyright holder.
`NOTICE` carries the attribution, `package.json` and `Cargo.toml` declare the
licence, and the About dialog shows the licence text embedded from `LICENSE` at
build time — the terms travel inside the binary rather than beside it.

The name is not part of the grant: a fork is welcome, a fork called Guazzo is
not.

## The repository builds for strangers

`src-tauri/.cargo/config.toml` used to be committed, and it rewrote the
crates.io source to a local mirror on `127.0.0.1:5189`. A clean clone therefore
failed at `cargo fetch` with exit 101 and "failed to get serde". The file is now
gitignored, `.cargo/config.toml.example` documents the sandbox setup, and
`CARGO_HOME` is optional instead of load-bearing. The published archive's
`app-single.html` was rebuilt from a fresh clone of the tag and matches
`RELEASE.json`.

## PSD compatibility is documented

`docs/COMPAT.md` states the contract: which features import live, which come
back as editable recipes, which are baked and reported, and why export writes
either the whole tree or one flattened layer — a group composites as one source,
so a half-tree would change the picture while looking like it worked. It also
lists what is deliberately not carried (smart objects, effects, layer comps,
video, 3D, CMYK editing, 16-bit precision) and the text guards.

## Verifying the download

```
sha256sum -c SHA256SUMS.txt
```

`SHA256SUMS.txt` covers the exe, the loader, the notices and the single-file
build; `Guazzo-v1.1.0.zip.sha256` covers the archive itself.

## Known limitation

The release binary carries two `RT_MANIFEST` resources because the icon
resources and Tauri's manifest both declare one. Windows reads the first, which
omits `longPathAware`, so paths longer than 260 characters may fail. DPI
awareness is unaffected: the runtime sets per-monitor-v2 itself at startup. The
fix is scheduled for 1.1.1.

## Requirements

Windows 10 or 11 with the WebView2 runtime (present on current Windows). Keep
`WebView2Loader.dll` beside `Guazzo.exe`. The binary is unsigned, so SmartScreen
shows "Windows protected your PC" on first run — choose **More info → Run
anyway**. A portable build needs no installer and no administrator rights.
