# Guazzo 1.17.1 — Brush Settings as a live panel

1.17.0 put the thirteen sections behind a modal dialog: pick numbers, press OK,
close it, then look at the canvas. That is the wrong loop for a brush. This
release turns the same panel into a floating window you paint under.

## What changed

- **No modal.** The panel is a `.float-win` above the panels and below a real
  dialog. There is no backdrop, so the canvas still takes a stroke while the
  panel is open; moving the pointer to the canvas does not close it.
- **Live, not staged.** Every slider and checkbox writes into the brush recipe
  and reports it immediately. There is no OK button, because there is nothing
  left to confirm: the next dab on the canvas is the confirmation.
- **One size.** 560 × 452, fixed. The section list and the controls each scroll
  inside their own column, so choosing Texture no longer makes the window jump
  wider or taller. Position is remembered between sessions, and clamped to the
  window on open.
- **The bar follows.** Size, Hardness, Smooth and Scatter on the options bar
  are the same numbers the panel edits. Changing Tip Size in the panel moves the
  bar's thumb instead of leaving two values that disagree.
- **Interface repairs.** Reset returns every section to its default; the header
  says "applies to the next stroke", which is the one thing a modal was
  implying; the preview is 512 px wide and runs the real `dabVariation` maths;
  the list is a tablist with arrow keys, and focus lands on the current section
  when the panel opens and returns to the Brush Settings button when it closes.

## Verification

- `scripts/ui-smoke.mjs` asserts: the panel is a `.float-win` and **not** an
  overlay; opening it adds no modal to the document; inline size is 560 × 452
  before and after switching sections; the thirteen sections are indexed; focus
  lands inside on open; a toggle is persisted without any OK button; Escape
  closes it and focus returns to the opener.
- Each of those was mutation-probed: removing the live report, the focus call,
  the Escape branch, the class that makes it a window, or the fixed height each
  turns the suite red (probe results in the commit message).
- Full gate green: `72 test files / 735 tests`, pins, smoke, deterministic
  single-file build.
