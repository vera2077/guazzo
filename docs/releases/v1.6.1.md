## 1.6.1 — the interface review pass

An independent review of the shipped 1.6.0 interface found eight defects; all of
them are fixed here, plus four the pass found while confirming them. None of
these change the document format.

**What could hurt you**

- The command palette could lock itself open for the rest of the session. Pressing
  Enter on a greyed command set the "closed" flag before the branch that keeps
  the palette up to explain why, so Escape, a click outside and every later
  Enter returned early — and because the palette is registered as a modal, it
  swallowed every shortcut with no visible way out. It now closes normally and
  says which command was unavailable.
- Cancelling the unsaved-changes prompt could leave the window unquittable
  (fixed in 1.4.0, now pinned by a test that fails if Escape bypasses the
  cancel path again).

**What was wrong on screen**

- A half-drawn crop survived a tool switch: the canvas stayed dimmed, the
  options bar lost Apply, and Enter cropped the document from any tool.
- The tab strip did not repaint after a switch, so the previous tab kept the
  highlight and the roving tab stop while a different document was on screen.
- The status bar clipped its right-hand end at narrow widths, which could hide
  the persistent error slot — the one place a failure is meant to stay.
- The floating Adjustments palette sat above modal dialogs, so it stayed
  visible and draggable over Export As, About and the close prompt.
- The Layer menu advertised `Alt+Ctrl+G` for Create Clipping Mask; no such
  binding has ever existed. The label is gone rather than the shortcut faked.
- Escape inside a submenu closed the whole menu bar instead of stepping back
  to the parent row.
- The layer context menu's clipping command is now reachable without a
  shortcut claim, and the palette traps Tab instead of letting focus walk into
  the canvas behind it.

**Keyboard and rendering**

- The viewport renders at the display's device pixel ratio. At 150 % Windows
  scaling the canvas was sized in CSS pixels, so every retouched pixel was
  resampled by the browser — soft, and worst exactly where brush work is judged.
- History rows are focusable and jump with Enter/Space, with `aria-current` on
  the step the document is at.
- Switching tabs scrolls the active tab into view; the strip hides its
  scrollbar, so an off-screen active tab had no visible affordance.
- Space-drag pans; the duplicate second mechanism for it was removed, so
  holding Space borrows the hand cursor and releasing restores the tool.

**Verification**: `node scripts/ci.mjs` → 61 test files / 648 tests, pins,
smoke and the deterministic single-file build. Each fix above has a smoke or
unit assertion, and each was mutation-probed: reverting the fix makes the
assertion fail (the Tab trap, the disabled-row latch, the crop cancel, the
strip repaint, the DPR sizing, the space-drag flag, the submenu Escape, the
modal/floating z-order, the status-bar clip and the error flex were each
reverted individually and produced the expected failures).
