# Guazzo 1.15.0

## What changed

**A one-file installer.** `Guazzo-v1.15.0-Setup.exe` writes the app into
`%LOCALAPPDATA%\Programs\Guazzo`, adds a Start-menu shortcut and registers
itself in **Settings ▸ Apps**, all without an elevation prompt — it installs for
the current user, so nothing system-wide changes and no UAC dialog appears for
an unsigned binary. `--uninstall` (and the Apps entry) removes the files, the
shortcut, the registry entry and then the uninstaller itself. `--silent`,
`--dir <path>` and `--no-shortcut` exist for scripts and for the build's own
test, which really installs and really uninstalls before the release is staged.

**Winget manifests.** `packaging/winget/` carries the three YAML files
(version, installer, `en-US` locale) for the setup exe, validated with
`winget validate`. Submitting them to `microsoft/winget-pkgs` is the remaining
step; until then `winget install Guazzo.Guazzo` will not resolve.

**The "low-resolution" rendering, explained and fixed.** The canvas was drawn
with `imageSmoothingEnabled = false` at **every** zoom level. That is right at
100 %/200 % and wrong everywhere else: at 93 % two source pixels had to become
one, so one row in fourteen was dropped — strokes looked chewed — and on a
125 % or 150 % Windows display even "100 %" is a non-integer scale, so the
whole canvas was nearest-neighbour resampled. `src/ui/zoomfilter.ts` now decides
per frame: crisp (nearest, and offset snapped to whole device pixels) only when
the zoom lands on an integer number of device pixels, smooth (`high` quality)
otherwise.

One honest limit: there is no hidden resolution to recover. At 93 % the screen
has fewer pixels than the document, so *some* resampling is unavoidable; what
changed is that it is now a proper filter instead of dropped rows. To see the
document at its true pixels, use 100 % on a 100 % display (or 200 % on a 200 %
one).

## Verification

- `70 test files / 703 tests`; lint, pins and smoke green; deterministic
  single-file build.
- Installer: installed into a workspace folder, every file asserted, then
  uninstalled and the folder polled until it disappeared — `build-setup:
  installed and uninstalled cleanly`.
- Zoom filter: 100/200/300 % crisp, 93 % and 1.25/1.5 device scales smoothed,
  `1/3 × 3` floating-point drift still counted as crisp.
- The published zip and the setup exe were re-downloaded and re-hashed after
  release.

## Limits

- Unsigned: SmartScreen will warn on the installer and on the app.
- The installer is per-user by design; there is no machine-wide option.
- winget submission is prepared, not accepted; the package id will only resolve
  after the manifests land in `microsoft/winget-pkgs`.
- Uninstall deletes the install folder; it does not delete documents or the
  WebView2 data folder under `%LOCALAPPDATA%\Guazzo`.
