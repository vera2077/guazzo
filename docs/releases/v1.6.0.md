# Guazzo 1.6.0

Channel Mixer is a live adjustment, and Photoshop keeps the weights.

## What changed

- **Channel Mixer is a real adjustment layer kind.** Each output channel is a
  weighted sum of the *source* channels plus a constant, in percent — Red,
  Green and Blue, with an optional **Monochrome** gray mix that turns all three
  outputs into one luminance. Live, masked and blendable like the rest.
- **One channel at a time.** The dialog shows a channel picker and four
  sliders (Red %, Green %, Blue %, Constant); switching channels keeps each
  channel's own numbers, so a three-channel mix is editable on a small dialog.
- **PSD round-trip.** Export writes `channel mixer` with per-channel
  `red/green/blue/constant` weights and, when monochrome is on, the `gray`
  channel and the `monochrome` flag; import reads them back into the recipe.
  These two records used to be admitted wholesale — the admission is gone.
- **Off-by-identity, not off-by-zero.** A mixer with no stored weights renders
  as identity (100 % of the matching channel), which is what Photoshop's own
  default record means; the sanitiser clamps to ±200 and the reader falls back
  to zero only for a channel the file does not carry.

## Verified

- `61 test files / 648 tests` green, 85 pins, smoke, deterministic artifact.
- Engine: identity passes every channel through, a green←red swap proves the mix
  reads the original pixels (not successively mixed ones), and the monochrome
  mix produces equal channels.
- PSD: record shape, `ag.writePsd` → `readPsd` → import returns the same
  weights, monochrome writes `gray`, and `psdExportLoss` reports nothing blocked.
- Project: weights (including gray) survive save/load and the composite is
  byte-identical.
- Smoke edits Green's red weight, switches to Blue and back to Red, and asserts
  each channel kept its own numbers and that the saved project agrees.
  Mutation probe: dropping the save-on-switch fails "the green channel's red
  weight is saved".

## Limitations

Unsigned executable (SmartScreen will warn), no installer, no auto-updater.
Selective colour and colour lookup are still not live kinds.
