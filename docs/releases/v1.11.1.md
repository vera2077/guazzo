## Guazzo 1.11.1

The Layers panel footer is one row again.

It carried eleven 26 px buttons. Below roughly 360 px of panel width they wrapped
into a second row, and the wrap did not merely look untidy: Merge Down and Delete
ended up a couple of pixels apart, with Delete directly beneath the duplicate
button. Nothing warned you before the click.

- Seven commands, always one row: New layer, Duplicate, Move up, Move down,
  Layer mask, New adjustment layer, Delete — with thin rules grouping them and a
  spacer that pushes Delete to the far edge.
- The four that left the row — Free Transform, Create Clipping Mask, Merge Down,
  Flatten Image — were already in the layer context menu or the Layer menu, so
  nothing became unreachable. The context menu still carries all of them.
- 24 px targets at the panel's 210 px minimum width: 7 × 24 + rules + padding =
  190 px, so the row fits without shrinking any target below the 24 px minimum.

### Verification

- 66 test files / 682 tests, gate green.
- Smoke pins the shape rather than the appearance: exactly seven commands, Delete
  last, no secondary command in the row, exactly one spacer, and the `.card-foot`
  rule must declare `flex-wrap: nowrap`.
- Probes: restoring the wrap declaration turns the nowrap assertion red; adding
  an eighth button turns the count, the Delete-is-last and the
  secondary-commands assertions red.
- The clip toggle probe moved with the command: it now opens the layer context
  menu and clicks Create Clipping Mask, instead of clicking a strip button that
  no longer exists (the old guard would have no-opped in silence).
