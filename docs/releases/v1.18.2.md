# Guazzo 1.18.2

A correctness release about three things that were quietly wrong: a smart
object could move, a release could not be proved, and a focus ring could land
somewhere the user never asked to be.

## What could hurt you

- **A smart object scaled from the visible sliver after Replace Contents.**
  When the replacement image was larger than the canvas, one transform
  rendered the whole source at 80 % of its natural size and clipped it. The
  source now keeps its resolution when the footprint fits, and a footprint
  clipped by the canvas is rasterised deliberately — with an undo that
  restores the source — instead of being guessed at.
- **A clipped transform landed up to half a pad away from the preview.**
  The preview pivots on the footprint; the commit pivoted on the padded tile
  rectangle. Both now pivot on the same box, mask included.
- **An empty smart layer lost its source.** A project can carry a smart source
  with no painted pixels; transforming it was treated as the edge case, so it
  dropped the source without an undo entry that could bring it back. It now
  refuses with a hint and keeps the source.
- **Setup could not prove what it installs.** `build-setup` now runs the built
  Setup with `--extract-payload`, hashes the bytes it reports, and refuses a
  mismatch; the payload ships in the release and `verify-asset` compares every
  embedded file to the release file byte-for-byte. A scratch release proved
  both halves of this were broken before it worked: the hash helper was being
  handed bytes as if they were a path, and the comparison looked for
  `Guazzo.exe` while the release ships `Guazzo-v<version>.exe`.
- **The installer could be talked into an autostart folder.** The
  System32/Startup denylist ran before the path was canonicalised, so a
  junction or an 8.3 alias inside `%LOCALAPPDATA%` slipped past it. The
  resolved path is checked against the same list now, and the writability
  probe uses `create_new` (it used to truncate any user file called
  `.guazzo-write-test`), while the failure log appends instead of replacing
  a file that may be the user's.
- **A release folder profile could not install at all.** The scope check
  compared a canonicalised path against raw environment roots; a profile
  redirected to another drive, or a UNC profile, matched nothing. Both
  spellings are compared now.
- **A manifest without installer sources skipped every payload check.**
  `verify-asset` now requires the list; a pre-anchoring manifest is refused
  unless `GUAZZO_ACCEPT_LEGACY_MANIFEST=1` asks for it.
- **The PSD parse limit was flat.** It is now derived from the header (three
  canvas-sized buffers, floored at 96 MB), so a small document cannot be made
  to allocate the full 768 MB parse budget.

## What was wrong on screen

- Resizing a text box moved keyboard focus into the Layers tree — a copy of
  the layer-tag focus restore, in a call site that never rebuilt a row.
- With everything undone, the History list lost its only tab stop, so the
  keyboard could not reach redo.
- Right-clicking a layer selected it but left the roving tab stop on the
  previous row.
- The curve editor claimed the arrows nudged "the last point" while they
  nudge the selected one, moved endpoints horizontally (which a drag cannot
  do), and changed the curve silently; it now clamps endpoints and announces
  "Point N of M: input X, output Y".
- The options bar — where focus is deliberately parked — was an unnamed,
  role-less div. It is now `role="toolbar"` with a name.
- Five submenu rows read "Colour Tag ▸ ›": the label already carried a glyph
  and the popup added another, inside the accessible name.

## Verification

- `79 test files / 804 tests`, pins, headless smoke, deterministic single-file
  build — all green; the release-time steps are the ones this version fixes.
- `verify-asset 1.18.2` reports `payload.bin matches 6 release files` and the
  archive hash, on the published bytes.
- The installer was exercised with a scratch release: install, version
  detection (Update/Reinstall), uninstall, and the embedded-payload proof.
