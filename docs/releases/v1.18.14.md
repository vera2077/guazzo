# Guazzo 1.18.14

This release completes the non-model Photoshop coverage rows and adds the
model-dependent rows as deterministic heuristics, explicitly labelled partial
rather than semantic. It also improves 16-bit PSD channel fidelity.

## New tools and commands

- Healing Brush with an Alt-click sampled source, Rounded Rectangle and a heart
  Custom Shape preset, Rotate View (15 degree canvas rotation with inverse
  pointer mapping), and Slice / Slice Select from the current selection.
- Art History Brush (Alt+Y) paints deterministic stylised strokes from a
  captured source with tight/medium/loose style and fidelity, clipped by the
  selection. Curvature Pen (Alt+P) derives smooth handles at close; Path and
  Direct Selection (A) marquee, drag and delete anchors.
- Smart Filters keep an editable blur/sharpen/emboss/noise stack on a smart
  object, re-rendered from source and saved with the project. The Filter
  Gallery adds Poster Edges, Colored Pencil, Rough Pastel, Canvas Texture and
  Note Paper; blur adds Lens, Field, Iris and Tilt Shift radius rows.
- Vertical Type and Type on Path transform the committed glyph raster; Type
  Mask turns new text into an undoable glyph-alpha selection and explains its
  new-text-only limit in-app.
- Object Selection refines the current selection rectangle with GrabCut-style
  colour histograms. Subject / Sky grows the sky from top-row colour and takes
  the subject as its complement. Focus Area scores local variance and edge
  energy at an editable conservative threshold. Content-Aware Move / Remove
  fills a selected rectangle with deterministic exemplar patches. All four are
  labelled partial: they are heuristics, not semantic segmentation.
- 16-bit PSD channels round to the nearest 8-bit level instead of truncating;
  import reports state the bit depth and the 8-bit compatibility path.

## Scope note

No offline segmentation or content-aware model is shipped. Heuristic rows are
coverage experiments with honest labels, not parity claims. Frame, Actions,
3D / Video / 360 remain out of scope.

## Still open

The Windows build is unsigned, so SmartScreen will warn on first run. Semantic
versions of the heuristic rows need an approved offline model with weights,
runtime, licensing, CI and security work.
