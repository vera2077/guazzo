## Guazzo 1.12.0

Hold the brush still and paint keeps arriving, the way an airbrush behaves.

Holding a stroke in place used to do nothing after the first dab: the pointer
had to move for paint to land. An **Airbrush** toggle now sits next to the
brush options and, while a brush or eraser stroke is down, deposits at a fixed
interval at the resting point.

- One deposit every 40 ms, at a fixed fraction of a dab (35 %), so the Flow
  slider still decides how fast the stroke builds rather than being bypassed.
- The timer belongs to the stroke: pressing starts it (the press itself is the
  first deposit), moving re-points it without double-painting the path, and
  releasing stops it. Starting a second stroke clears the first timer instead of
  stacking two.
- The toggle is off by default and reports its state (`aria-pressed`), because a
  mode that changes what a click does should not be invisible.

### One limitation, stated plainly

A held airbrush accumulates toward full opacity, so on a partially transparent
Opacity setting the stroke can pass the slider. Photoshop caps the whole stroke
at the Opacity value; doing that here needs per-stroke coverage tracking in
`StrokeSession` (an engine change, not a UI one) and is not in this release.
Flow is the cap in practice: the deposit per tick is a fraction of a dab.

### Verification

- 67 test files / 687 tests, 86/86 pins, gate green.
- Engine: repeating a dab at one point accumulates toward opaque (the timer
  test cannot see pixels, so the accumulation is pinned where pixels live).
- UI: four timing tests drive a fake clock — press deposits once then once per
  tick; moving re-points without depositing; a second press clears the first
  timer; the tick fraction is strictly between 0 and 1.
- Smoke, executed rather than grepped: the toggle exists and flips
  `aria-pressed`; a press registers exactly one 40 ms timer; a tick reaches the
  canvas; releasing clears the timer. Probes: removing `airbrush.start(...)`
  fails "holding the brush must start exactly one airbrush timer (got 0)";
  making the deposit return early fails "an airbrush tick must reach the canvas
  (105 -> 105)".
