# Guazzo 1.4.1

Keyboard focus, fixed where the last review found it missing.

## What changed

- **Tab no longer hides the panel you are standing in.** Tab is Photoshop's
  panel toggle, but it applied everywhere — so F6 could put focus in the layers
  panel and the very next Tab hid it. The toggle now only fires from the canvas;
  inside the chrome, Tab is left to the browser and walks the controls.
- **F6 remembers where you were.** Each region keeps the control you last
  focused, so coming back to the layers panel lands on your layer instead of
  resetting to the first row, and a second F6 moves on as before.
- **Context menus return focus to the row**, not to a label span. Escape from a
  layer's context menu used to drop focus to `<body>`; it now lands on the row
  you right-clicked.

## Verified

- `61 test files / 637 tests` green, 85 pins, smoke, deterministic artifact.
- The Tab rule is mutation-probed: disabling the chrome check makes the smoke
  fail with "Tab inside the chrome must be left to the browser, not swallowed".
- The smoke now exposes `HTMLElement` and `document.querySelector('#id')` to the
  bundle's context. Both were missing, which is why the F6 path had never
  actually executed in the gate — the test was green because the code it was
  meant to exercise threw and the error was not observed.

## Limitations

Unsigned executable (SmartScreen will warn), no installer, no auto-updater.
