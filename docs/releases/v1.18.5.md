# Guazzo 1.18.5

A correctness release for the recovery path, and for the gestures that could
take a selection away without an undo step.

## What could hurt you

- **A second boot could destroy the older crashed session.** 1.18.4 parked the
  offered snapshot in its own recovery slot, but on the next launch both the
  live and recovery slots held the same bytes — so "the second newest" was a
  duplicate, and writing it over `guazzo-autosave-older.json` erased the only
  copy of the other session. Boot now writes nothing when the copies are
  already identical, and the live slot is never written at boot.
- **Restore deleted the crash slots before the restored tabs were on disk.**
  If the write failed, the recovery bar was gone and the snapshot with it.
  Restore now keeps both slots until `writeAutosave` succeeds, then drops only
  those two.
- **Starting a polygon discarded the selection you had.** The first click
  cleared the old mask, and a cancel (Escape, fewer than three points) left
  nothing behind and no undo entry. A cancel now restores the previous
  selection, Shift/Alt are honoured at commit, and the whole gesture is one
  history step.
- **An ellipse click wiped a live selection with no way back.** The zero-size
  branch now records an undoable Deselect, like the marquee already did.

## What was wrong on screen

- The recovery bar was mouse-only and unannounced. It is a labelled alert,
  takes focus on Restore, and Tab stays inside it instead of jumping to the
  hidden panels.
- Merge Down refused a group or an adjustment layer with a sentence about
  layer styles — the wrong cause. It now says the layers must be pixels and
  which side to convert.
- PSD export flattened a smart object and said nothing. The loss note now
  names the layer and says the source image is not embedded.
- A dialog whose OK rebuilt the layer strip returned focus to `<body>`, so the
  next Delete erased the selection. The fallback order is the opener, then the
  active layer row, then the active tab.

## Verification

- `79 test files / 809 tests`, 113 static pins, and the headless UI smoke.
- Probes: re-adding the boot delete reddens the banner assertion; dropping the
  duplicate guard reddens the parking pin; removing the polygon restore
  reddens the selection assertion; restoring the flat 65535 alpha division
  reddens the 32-bit PSD test.
- `verify-asset` proves the Setup embeds the payload the manifest attests, and
  the packaged zip is re-downloaded and hashed before a release is announced.
