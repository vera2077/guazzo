# Guzzo 1.2.3

Two follow-ups from the same review that produced 1.2.2: the performance work
needed tests that could fail, and deleting a group needed a question first.

## Fixed

- **Deleting a group that holds layers asks before it goes.** The layer-footer
  trash button is labelled "Delete layer"; on a group it removed the whole
  subtree with no confirmation, and undo was the only way back. The prompt says
  how many layers the group holds, and the deletion re-checks that the group is
  still in the document, because the answer arrives after a dialog.

## Tests that can now fail

- **Perspective Crop's strip loop.** Every fixture was 8×8 while the warp reads
  the source in 64-row strips, so the loop ran exactly once: a regression that
  always wrote at row 0 — dropping everything below row 63 — passed the suite.
  The new fixture is 200×140 with a quad that spans two strips.
- **The Move union window.** The fixture fit inside a single 256 px tile, so the
  tile-aligned bounds were always the whole canvas and the union arithmetic was
  never exercised; dropping the destination term from the union survived. The
  new fixture is 600×600 with the content inside one tile away from the origin,
  compared against a naive full-canvas reference by first differing pixel (a
  failing `deepEqual` on 1.4 MB of pixels takes a minute to format).
- Both mutants were re-run against the new fixtures and fail them.

## Verify

`sha256sum -c SHA256SUMS.txt` inside the extracted zip. The archive's
`RELEASE.json` names the commit, the build inputs and the artifact hash; a
`v1.2.3` clone rebuilds `app-single.html` byte-identically.

## Known limitations

Unchanged from 1.2.2: the exe is unsigned (Windows shows "Unknown publisher"),
there is no installer or updater, 16-bit PSDs import as 8-bit with an admission,
and the two documented 16k limits are in `docs/PERFORMANCE.md`.
