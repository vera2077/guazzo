# Guazzo 1.1.1 — one manifest, and release notes that survive a restage

Two internal fixes. The editor behaves exactly as it did in 1.1.0; if you only
care whether the app still works, this release is not urgent.

## Fixed

**Windows now reads one complete application manifest.** The executable carried
two `RT_MANIFEST` resources — one from the C toolchain (`longPathAware`,
`asInvoker`) and one from the GUI framework (Common Controls v6) — and the linker
kept whichever came first, so the manifest Windows actually honoured had no
`longPathAware`. Every release also printed `.rsrc merge failure: multiple
non-default manifests`, which was the collision itself. Guazzo now supplies a
single manifest carrying the whole set: Common Controls v6, `asInvoker`,
per-monitor-v2 DPI awareness, and long-path awareness. Paths longer than 260
characters open, and the warning is gone.

**Release notes are part of the release, not a manual step.** `release.mjs` wipes
`release/<version>/` and rebuilds it from a fixed list of files, which meant the
notes had to be pasted in afterwards — and a restage silently deleted them (it
happened once, on 1.0.0). They now live at `docs/releases/v<version>.md`, are
copied into the folder as `RELEASE-NOTES.md`, are covered by `SHA256SUMS.txt`, and
staging refuses to run when the file is missing. The notes are not inside the zip:
they describe the archive, they are not payload.

## Verified

- `node scripts/ci.mjs` green: 59 test files, 600 tests, 83 static invariants,
  deterministic single-file build.
- The artefact rebuilds byte-identically from this tag; the zip is deterministic
  and its extracted contents pass `sha256sum -c`.
- The staged manifest was read back out of the built executable and contains all
  four settings above.

## Same as 1.1.0

Layers and groups with pass-through, masks, ~30 filters, 13 adjustment kinds,
selections and Select and Mask, pen, text with paragraph alignment, healing,
transform, crop, PSD import/export with a documented fidelity contract, project
save/load, autosave, tabs, native dialogs.

Read `docs/COMPAT.md` for what PSD import and export actually preserve. It is a
list of what is guaranteed and what is admitted, not marketing.

## Known limitation

The build is unsigned, so Windows SmartScreen may ask before the first launch:
choose **More info → Run anyway**. There is no installer and no auto-updater; the
app is a folder you extract and run.
