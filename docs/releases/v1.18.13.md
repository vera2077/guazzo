# Guazzo 1.18.13

This release implements the five deferred Photoshop coverage rows that do not
need a machine-learning model: Custom 5x5 kernel, Reduce Noise, History Brush,
path anchor editing / Make Work Path, and Apply Image / Calculations.

## New tools and commands

- History Brush (Y): capture a snapshot from the current layer state, return to
  the state being edited, then paint to restore the captured pixels. Size,
  Hardness, Opacity and Flow are in the options bar; the selection clips the
  stroke and the whole stroke is one undo entry.
- Image > Apply Image composites another pixel layer into the active layer with
  Normal, Multiply, Screen, Overlay, Difference, Add or Subtract and an opacity.
  Image > Calculations blends one channel from two layers into a new selection.
  Nested pixel layers are valid sources; selection and opacity clip both.
- Image > Make Work Path traces the outer contour of a selection into editable
  Pen anchors, including Select All (the canvas border). The Pen now supports
  Alt-click delete, Ctrl+double-click corner/smooth conversion, double-click or
  Enter to close, Shift-drag to move, and draggable curve handles.
- Filter gallery: Reduce Noise removes specks with a strength-driven 5x5 median
  while preserving hard edges. Filter > Other > Custom 5x5 opens a 25-cell
  coefficient dialog with Scale and Offset.

## Scope note

Object Selection, Subject/Sky, Content-Aware Move/Remove and other
model-dependent rows remain out of scope. Guazzo has no offline segmentation or
content-aware model; docs/PHOTOSHOP-COVERAGE.md marks those rows explicitly
rather than claiming a heuristic as parity.

## Verification

- node scripts/ci.mjs: 83 test files / 853 tests, pins 120/120, smoke and the
  deterministic single-file build.
- Coupling remains 88/331 top-level functions in src/main.ts; no new coupled
  top-level function was added.
- Every new behavior has a test or pin that fails when the behavior is removed,
  and each fix was mutation-probed red then restored green.

## Still open

remaining Photoshop coverage rows need models Guazzo does not have.
