# Guazzo 1.18.12

A review-polish release. No new tools or document features; this closes the remaining minor and nit findings from the 44–46 review loop and hardens the release tooling.

## Interface and accessibility

- The autosave-recovery bar and its label wrap instead of clipping in narrow windows, and long document names no longer get cut off.
- Status errors show the full message on hover and can be selected and copied without dismissing them.
- An earlier-snapshot notice is named once, not duplicated by the discard or restore paths.
- The Layers Blend selector has an accessible label, help and notice text can be selected, and marching ants respect `prefers-reduced-motion`.

## Engine and tests

- Mask transforms release fully revealed tiles regardless of stored alpha, so a swept fully revealed tile stays sparse across tile boundaries.
- Added regression tests for the neutral read of released hide-mask tiles, the mask undo/redo round trip, and the swept-reveal sparsity case.

## Release and documentation

- `verify-asset.mjs` validates the version argument even when called as a library, so a path-shaped version cannot escape `release/`.
- `winget.mjs` and `build-setup.mjs` resolve the repo root with `fileURLToPath`, so checkouts with spaces or `#` work.
- Workflow pins now assert `permissions: contents: read` in both workflows.
- Corrected stale rows in the Photoshop coverage plan, publishing and signing docs, and the README changelog.

## Verification

- `node scripts/ci.mjs` — 80 test files / 827 tests, pins, smoke, and the deterministic single-file build.
- Static pins: 115/115. Key fixes were mutation-probed red then green.
- `verify-asset.mjs` checks the zip, Setup and payload against `RELEASE.json` and the committed `installer/assets/payload.bin`.

## Still open

The deferred Photoshop rows in `docs/PHOTOSHOP-COVERAGE.md` need models Guazzo does not have. The Windows build remains unsigned.
