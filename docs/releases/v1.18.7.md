# Guazzo 1.18.7

Two claims in the 1.18.6 notes were not true of the shipped build. This release
makes them true, and fixes three smaller ways the recovery screen could mislead.

## What was wrong in 1.18.6

- **Tab did not cycle the recovery bar.** The bar's handler picked a fixed
  button from `shiftKey` instead of moving from the button you were on, so Tab
  from Discard pressed Discard again and Shift+Tab from Restore pressed Restore
  again. A keyboard-only user could not decline the question.
- **A saved session was still offered as crash work.** The snapshot records
  "clean" from the tabs' dirty flags, but saving never asked for another
  autosave tick, so the on-disk snapshot kept `clean: false`. Saving and
  quitting still produced "Found an unsaved autosave" on the next launch — the
  exact case the release claimed to fix.

## What changed

- The recovery bar cycles Restore → Discard → Restore with Tab and back with
  Shift+Tab, proved by firing both stuck directions in the smoke.
- Saving sets every tab's autosave flag, captures the tab and asks the scheduler
  for a tick, so the next snapshot carries `clean: true`. The clean snapshot is
  dropped at the next boot; a document you saved is not "lost work".
- Leaving the polygonal lasso, by tool switch or shortcut, cancels the polygon
  the same way Escape does: the selection from before the first click comes
  back, with its hint. It used to drop both the polygon and the selection.
- A restore that cannot rebuild some or all documents now says so, names them,
  and leaves the crash slots in place. A total failure keeps the bar instead of
  hiding it and appearing to do nothing.
- Merge Down explains the two cases where `Ctrl+E` used to do nothing silently:
  a live transform, and a layer with nothing below it.

## Verification

- `node scripts/ci.mjs` — 79 test files / 810 tests, 113 pins, smoke, and the
  deterministic single-file build.
- Smoke: Tab and Shift+Tab both cycle the bar in both directions; the earlier
  recovery assertions (offered copy parked in its own slot, Restore keeps the
  slot until the tabs are written, crash slots gone afterwards) still pass.
- The installer payload is still proven against the shipped Setup, and
  `verify-asset` still requires the installer hash and the Setup entry.

## What this does not fix

The deferred Photoshop rows in `docs/PHOTOSHOP-COVERAGE.md` still need models
Guazzo does not have (Object Selection, Make Work Path, path editing,
History/Art History brush, Content-Aware Move, vertical type, and the
Channels/Paths/Actions panels). The Windows build is unsigned.
