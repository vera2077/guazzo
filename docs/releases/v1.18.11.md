# Guazzo 1.18.11

An installer-only fix: the Setup no longer opens a console window.

## No terminal behind the installer

The desktop app has always been built as a Windows GUI-subsystem binary, but
the installer crate was not. Launching Setup directly gave you a console
window behind the dialog. `installer/src/main.rs` now sets
`windows_subsystem = "windows"`, so only the installer window appears.

Silent and uninstall modes are unchanged: they still report failure through
the exit code and the on-disk log file.

The PE header of the shipped Setup was checked: subsystem 2 (GUI), not 3
(console), and the installer's install/uninstall smoke test still passes.

## Verification

- `node scripts/ci.mjs` — 80 test files / 823 tests, pins, smoke, and the
  deterministic single-file build.
- `verify-asset.mjs` checks the zip, Setup and payload against `RELEASE.json`
  and the committed `installer/assets/payload.bin`.
