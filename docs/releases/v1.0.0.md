# Guazzo 1.0.0

Guazzo is a fully-offline, Photoshop-shaped image editor: layers and groups,
selections and masks, adjustment/fill/text layers, PSD import and export, and a
single-file browser build. This is the first stable release.

## What changed since 0.72.0

- **0.73.0** — mask-polarity round trips, masked adjustment layers, nested group
  export, PSD/TIFF parse caps, ARIA/group/keyboard UX, import/export honesty,
  mutation tests, performance work, build receipts and bounded IPC.
- **0.74.0** — a deterministic downloadable zip, one PSD export-loss decision
  shared by dialog/stats/writer, idle-debounced deflated autosave, faster
  Gaussian blur, export-canvas refusal, text recipe paths, and a 1.5 GiB PSD
  import budget.
- **1.0.0** — streaming v2 autosave: 4096² × 8-layer and 3-tab sessions now
  write and restore without building one >512 MB JSON string. No new editing
  capability was added.

## What it deliberately does not do

Cloud or generative features, online activation or licensing, CMYK/Lab colour
modes, 16/32-bit PSD writing, and a built-in update checker. The app is offline
forever, by design.

## Signing and updates

Guazzo 1.0.0 is **unsigned**. Windows shows "Unknown publisher", and SmartScreen
may warn on the first launch: choose **More info → Run anyway**. Code signing is
planned, not purchased.

Guazzo never checks for updates and contains no network code. To update, replace
the program folder with a newer release zip; existing `.guazzo.json` projects
keep working. There is no auto-updater and no network check.

No public download is published yet. The authoritative build is
`release/1.0.0/`.

header carries a linker timestamp — so verify it against `RELEASE.json` only.

## Known limitation

The exe embeds two `RT_MANIFEST` resources with the same id; Windows reads the
first, which omits `longPathAware`. DPI awareness is restored at runtime by the
window toolkit. Scheduled for 1.0.1, with a build-time check so it cannot recur.
