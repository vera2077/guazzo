# Guazzo 1.18.1

A correctness release. Nothing new to learn — four review rounds since 1.18.0
found paths where the editor did the wrong thing quietly, and the release
pipeline could not produce a release at all.

## What could hurt you

- **A hidden layer could be merged away.** Merge Down onto a hidden layer
  stamped the upper layer's pixels into it and deleted the upper layer, so both
  appeared to vanish (undoable, but silent). It now refuses, and says which
  layer to show first. It also refuses a smart object or a live type layer,
  because the merged result could no longer be re-derived or re-edited.
- **Geometry dropped what a layer was.** Image Size, Crop, Canvas Size, Rotate
  and Flip rebuilt the tree and lost group children, mask polarity and smart
  sources — a rotate could resurrect rows a crop had removed, because the smart
  object still pointed at the old frame. Geometry now rebuilds the tree, keeps
  the polarity, and clears a smart source it can no longer describe.
- **A stroke on the background eraser or colour replacement could not be
  undone.** Both wrote tiles outside the stroke session, so the history entry
  never existed. They now record their tiles like every other paint tool.
- **Delete, Cut and Fill on live type cleared pixels the recipe still owned.**
  The next Type edit re-stamped the old glyphs over whatever was underneath.
  All three now refuse and point at rasterising. Cut also refuses when the mask
  chip is lit instead of destroying the layer's pixels.
- **A save could mark an edit as saved.** Saving serialised the document,
  awaited the write, then cleared the dirty markers unconditionally; an edit
  during the write was lost on close. The markers now clear only if the
  document's revision is unchanged.
- **Autosave could write a snapshot its reader refuses.** It counted tiles and
  bytes but not layers; a session past 4,096 layers was written and then
  recovered nothing. It now refuses up front, visibly, and leaves the tabs
  dirty.
- **Arrow-key nudge moved the whole text recipe while only selected pixels
  moved**, leaving the raster and the recipe out of step.

## Keyboard and panel contracts

- Tab keydown stopped the default but not propagation: Delete on a focused tab
  erased the selection of the tab that had just come forward, Enter could run
  an armed crop, Space armed pan. The keydown now stops propagating.
- The Histogram card froze after every paint edit (it keyed on a generation
  that only moved on document swaps). It follows a monotonic stamp now, and
  documents over 4 MP coalesce the walk instead of blocking a pointermove.
- The Info card announced every pointer position through `role="status"`; it is
  a read-out, not a live region.
- The Clear buttons for Count/Notes/Samples/Ruler gained the labels the options
  bar matches, so focus no longer falls to `<body>` where the next Delete
  erased the selection.
- Patch, Count and Sampler hints were filed into the help panel by
  `finalizeOptionsBar` (they used `.label`), so the requirement they state never
  rendered. They are ordinary read-outs now.

## Release pipeline

- **No workflow could produce a release.** The job imported the signing
  certificate, signed the app exe, removed the key, and only then built the
  Setup — which could therefore only be unsigned; and the "unsigned" opt-out
  expression evaluated to `'1'` for every input. The certificate is removed
  after the installer is built, the Setup is signed whenever a certificate is
  configured, and `verify-asset` refuses a Setup the manifest does not name and
  compares the required signer.
- The job's version comes from `package.json`, not the ref name (a dispatch on
  `main` produced the version "main" and looked under `release/main/`).
- `release.mjs` accepts the detached HEAD a tag dispatch produces, while still
  refusing a checkout that is not that tag.
- The installer's graphical path now runs the same folder-scope rule as
  `--dir`, including components that end in a dot or a space.

## Verification

- Gate: 79 test files / 800 tests, pins, smoke, deterministic single-file
  build.
- New pins: the certificate is removed after the installer is built; the
  graphical installer checks the folder scope; a live type layer cannot be
  cleared, cut or filled; a save compares the revision; autosave counts layers.
